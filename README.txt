Complaint Tracker - Updated DSA Project

Added practical DSA modules:
Module 3 / CO-3:
- Merge Sort for complaint priority
- Binary Search for Complaint ID

Module 4 / CO-4:
- Edmonds-Karp maximum-flow model for assigning unresolved complaints to staff

Module 5 / CO-5:
- Greedy Set Cover approximation for staff coverage of pending complaints
- Demonstrates the NP-hard nature of exact set cover and an efficient approximation

Module 6 / CO-6:
- Randomized audit sampling of complaint records

Original CO-1 / CO-2:
- File-based complaint retrieval
- Z-Algorithm pattern matching

Compile:
javac ComplaintTracker.java

Run:
java ComplaintTracker
